# Portfolio Personnel

Un portfolio professionnel moderne construit avec Next.js et Chakra UI.

## Technologies Utilisées

- Next.js
- React
- Chakra UI
- Font Awesome
- Framer Motion

## Prérequis

- Node.js (version 14 ou supérieure)
- npm ou yarn

## Installation

1. Clonez le repository
```bash
git clone <votre-repo>
cd portfolio
```

2. Installez les dépendances
```bash
npm install
# ou
yarn install
```

3. Lancez le serveur de développement
```bash
npm run dev
# ou
yarn dev
```

4. Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur pour voir le résultat.

## Structure du Projet

```
portfolio/
  ├── components/     # Composants React réutilisables
  ├── pages/          # Pages de l'application
  ├── styles/         # Fichiers de style et thème
  └── public/         # Assets statiques
```

## Déploiement

Le projet peut être déployé sur Vercel, Netlify ou tout autre hébergeur compatible avec Next.js.

## Personnalisation

- Modifiez le contenu dans `pages/index.js`
- Ajustez le thème dans `styles/theme.js`
- Personnalisez les composants dans le dossier `components/`
